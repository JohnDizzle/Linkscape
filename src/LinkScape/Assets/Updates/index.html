AUGUST 11, 2026

Workspace activation and Windows Share

1.0.16
  • Open a validated package of active tabs through the link2scape protocol.
  • Append tabs to the current session or replace the active session.
  • Optionally save the resulting session and create or update a named Collection.
  • Share a page snapshot and URL from LinkScape, or preview an image shared to LinkScape.

TABS + COLLECTION

Open tabs and save a Collection

{
  "mode": "replace",
  "saveState": true,
  "collectionName": "Work Morning",
  "tabs": [
    { "title": "Outlook", "url": "https://outlook.office.com", "selected": true },
    { "title": "GitHub", "url": "https://github.com" }
  ]
}

TABS ONLY

Open tabs without a Collection

{
  "mode": "append",
  "saveState": false,
  "tabs": [
    { "title": "Docs", "url": "https://learn.microsoft.com", "selected": true },
    { "title": "GitHub", "url": "https://github.com" }
  ]
}
replace Replace the current active tabs with the package tabs.
append Keep the active tabs and add the package tabs after them.
saveState true saves the result for startup; false keeps it in this session.

Launch the package from PowerShell

$bytes = [Text.Encoding]::UTF8.GetBytes($json)
$payload = [Convert]::ToBase64String($bytes).TrimEnd('=').Replace('+', '-').Replace('/', '_')
Start-Process "link2scape://tabs/active?payload=$payload"
