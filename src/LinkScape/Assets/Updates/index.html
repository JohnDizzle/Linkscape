Open and share your workspace

Open a ready-made set of tabs from another app or script, optionally save those tabs as a Collection, and share images and pages in either direction with Windows Share.

ACTIVATION PROTOCOL

Open tabs with a simple package

Encode the JSON as Base64URL and place it after link2scape://tabs/active?payload=. LinkScape validates the package before opening it.

TABS + COLLECTION

Open tabs and save a Collection

The collectionName field also saves these URLs in a Collection named “Work Morning.”

{
  "mode": "replace",
  "saveState": true,
  "collectionName": "Work Morning",
  "tabs": [
    {
      "title": "Outlook",
      "url": "https://outlook.office.com",
      "selected": true
    },
    {
      "title": "GitHub",
      "url": "https://github.com"
    }
  ]
}

TABS ONLY

Open tabs without a Collection

Leave out collectionName. The tabs open normally, but no Collection is created or changed.

{
  "mode": "append",
  "saveState": false,
  "tabs": [
    {
      "title": "Docs",
      "url": "https://learn.microsoft.com",
      "selected": true
    },
    {
      "title": "GitHub",
      "url": "https://github.com"
    }
  ]
}
replace Replace the current active tabs with the tabs in the package.
append Keep the current active tabs and add the package tabs after them.
saveState true saves the resulting session for startup; false opens it for this session only.

Launch either package from PowerShell

Place either JSON example in $json, then encode and open it:

$bytes = [Text.Encoding]::UTF8.GetBytes($json)
$payload = [Convert]::ToBase64String($bytes).TrimEnd('=').Replace('+', '-').Replace('/', '_')
$uri = "link2scape://tabs/active?payload=$payload"
Start-Process $uri
